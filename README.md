🎮 B2+ Opinion Essay Planner | Unit 2 Writing Workshop

This interactive web tool is designed for B2+ level English preparatory students (10th Grade / Upper-Intermediate) to guide them step-by-step through planning, structuring, and drafting a 5-paragraph opinion essay.

🎯 Target Topic

Prompt: "Video games influence the way people behave in real life. Age restrictions should be enforced more strictly and some games should be banned completely."

(Based on Unit 2 - Developing Writing section)

✨ Features

Step 1: Stance & Thesis Statement — Choose a position (FOR/AGAINST) and build a strong thesis using B2+ starter frameworks.

Step 2: Brainstorming & Evidence — Organize pros, cons, and integrate real-life cases/examples (e.g., news incidents like GTA-related driver infractions).

Step 3: 5-Paragraph Essay Plan — Draft Introduction, 2 Body Paragraphs, Counterargument/Refutation, and Conclusion using B2+ target vocabulary.

Step 4: Self-Reflection & Writing Checklist — Check essay quality against B2+ linking devices and refutation strategies.

Step 5: Export Draft — Automatically aggregate all paragraphs into a clean text draft for easy copy-pasting to Google Classroom or e-mail.

🛠️ Built With

HTML5 & Vanilla JavaScript (Single-file web application)

Tailwind CSS (Responsive UI design)
